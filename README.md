# Практическая работа №4 — ближайший объект на карте

Вариант №3. Программа ищет ближайший объект выбранного типа с помощью k-d дерева
и показывает его на интерактивной карте OpenStreetMap.

## 1. Как запустить

Нужны **Python 3.11 или новее**, браузер и интернет. Поддерживаются Windows и Linux.
Дополнительные библиотеки Python устанавливать не требуется.

1. На GitHub нажмите **Code → Download ZIP** и распакуйте архив целиком.
2. Откройте папку с `app.py` в VS Code: **Файл → Открыть папку**.
3. Выберите **Терминал → Создать терминал** и выполните:

```sh
python app.py
```

Если в Linux команда называется `python3`, выполните `python3 app.py`.
Вместо VS Code можно использовать любой терминал, открытый в папке с `app.py`.

Откроется браузер с картой. Если он не открылся, вручную перейдите по адресу:

```text
http://127.0.0.1:8765
```

**Оставьте терминал открытым**, пока пользуетесь программой.
Чтобы остановить её, нажмите в терминале **Ctrl+C**.
Не переносите `app.py` отдельно: папка `nearest_map` и её содержимое нужны для работы.

## 2. Как найти объект

1. Выберите тип: кафе, ресторан, супермаркет, аптеку, больницу или банкомат.
2. Передвиньте карту мышью и измените масштаб колёсиком либо кнопками `+` / `−`.
3. Нажмите **«Использовать видимую область»** — появится синий прямоугольник поиска.
4. Нажмите на точку **внутри прямоугольника**. Она будет отмечена синим.
5. Нажмите **«Найти ближайший объект»**. Загрузка может занять до минуты.

Серые отметки — найденные объекты, красная — ближайший. Под кнопкой поиска появятся
название, адрес, расстояние в метрах и ссылка на объект. При необходимости
прокрутите левую панель вниз, чтобы увидеть карточку целиком.

Для перехода к другой точке можно ввести широту и долготу и нажать
**«Показать точку»**. После перемещения карты снова нажмите
**«Использовать видимую область»**, чтобы изменить район поиска.

Расстояние считается **по прямой на локальной плоскости, не по дорогам**.
Для площадных объектов используется центр их границ. Адрес загружается из OSM;
если его получить нельзя, программа сообщает об этом.

## 3. Если возникла проблема

- **Точка вне области:** выберите точку внутри синего прямоугольника или задайте новую область.
- **Нет объектов:** выберите другой тип или район.
- **Ошибка загрузки карты или данных:** проверьте интернет, приблизьте карту,
  выберите меньшую область и повторите поиск. Работа зависит от доступности API OpenStreetMap.
- **Нужны актуальные данные:** отметьте **«Загрузить свежие данные»**.
  Без этой отметки данные области могут использоваться из кэша до пяти минут.
- **Порт занят:** выполните команду ниже и откройте адрес, напечатанный в терминале:

```sh
python app.py --port 8766
```

Область поиска ограничена 40 км по каждой стороне. При недоступности Overpass
резервная загрузка работает только для небольших участков карты.

## 4. Проверка кода

Тесты выполняются без интернета:

```sh
python -B -m unittest discover -v
```

Для проверки качества кода установите Pylint и выполните:

```sh
python -m pip install pylint==4.0.8
python -B -m pylint --rcfile=.pylintrc app.py nearest_map tests
```
